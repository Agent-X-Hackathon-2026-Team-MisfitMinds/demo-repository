# Security policy

Report vulnerabilities privately through GitHub Security Advisories on `Agent-X-Hackathon-2026-Team-MisfitMinds/demo-repository` ("Report a vulnerability"). Do not open public issues for security bugs. We aim to acknowledge within 72 hours.

Scope highlights: sandbox escape or secret exposure to repository code, bypass of the nine gates, any path that lets Fixie merge, approve or mark a PR ready, or write refs outside `fixie/*`.
